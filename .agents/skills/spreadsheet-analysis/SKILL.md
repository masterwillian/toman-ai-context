# Skill: Spreadsheet Analysis

Use when answering questions from a workbook or CSV.

## Steps
1. Inspect workbook/sheet names and column schemas.
2. Restrict analysis to user-specified sheets if requested.
3. Search exact term plus obvious spelling/case variants.
4. Keep raw source fields.
5. Cross-reference related tables by stable identifiers.
6. Derive metrics only with explicit formulas.
7. Verify top-ranked rows before returning results.
8. State missing or ambiguous data rather than filling gaps.

## Output
Prefer a compact ranked table containing source values, derived value when used, and the relevant cross-referenced fields.
