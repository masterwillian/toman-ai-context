# Skill: Evidence-Driven Debugging

1. Reproduce/inspect the symptom.
2. Write down expected vs actual state.
3. Trace state across each system boundary.
4. Find the earliest divergence.
5. Patch the root cause with the smallest coherent change.
6. Re-run the same scenario.
7. Verify persisted/downstream state.
8. Report what was verified and what remains uncertain.
