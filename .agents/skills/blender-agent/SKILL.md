# Skill: Blender Agent Operations

## Goal
Make reliable scene changes through inspection and verification rather than blind scripting.

## Procedure
1. Inspect relevant scene objects and current transforms.
2. Plan exact operations with stable object names/IDs.
3. Apply one logical group of changes.
4. Re-inspect resulting transforms/dimensions/materials.
5. Render or screenshot when visual validation is needed.
6. Save a checkpoint after a verified milestone.

Prefer structured tools over arbitrary code execution when both are available.
