# Visual Multi-Agent Workspace

## Goal

Create a visual 3D/2D operational environment where visible agents correspond to real backend agent processes rather than decorative NPCs.

## Desired capabilities

- Click an agent to inspect state.
- Chat directly with an agent.
- Display balance/performance/state when relevant.
- Departments and hierarchy.
- Shared knowledge base.
- Logs and task history.
- Tool access and permissions.
- Human approval gates for risky actions.
- Persistent feedback/learning artifacts.

## Implementation principle

Prefer adapting a proven agent-office UI/runtime before rebuilding the entire visualization layer from scratch.

For financial/trading experiments, start with paper trading and explicit risk controls before any live broker integration.
