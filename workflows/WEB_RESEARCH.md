# Web Research Workflow

1. Determine whether fresh information is necessary.
2. Prefer official/primary sources for specifications, APIs, product behavior, and policy.
3. Use multiple independent sources when the claim is contested or consequential.
4. Separate current facts from historical context.
5. Include concrete dates for time-sensitive findings.
6. Do not let web results override user-provided source-of-truth files when the task is scoped to those files.
