# Durable Decisions

- GitHub should act as versioned long-term operational context; chats remain temporary working context.
- Shared AI behavior should be reproduced through explicit instructions, project knowledge, examples, and skills rather than account sharing.
- Secrets must not be stored in portable context repositories.
- Agents should load only the context relevant to the current task.
- A working implementation should be verified before adding complexity.
- Local AI workflows should use constrained tools and explicit verification to reduce loops and accidental edits.
